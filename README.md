# U - AI Ecosystem

This repository contains an AI ecosystem hub with multiple integrated components:

## Components

- **Hub** - Central control and navigation interface
- **VantaCore** - Backend API system (Python/Flask)
- **AI Dev Suite** - Development tools and interface (React/Vite)
- **Odin Protocol** - Protocol implementation
- **Warp Engine** - Engine component
- **Hyperfusion Core** - Core processing system
- **Metropolis Prime** - Primary management system
- **Tachyonic Bridge** - Bridge interface
- **Super KI** - Advanced AI system
- **Super KI Swarm** - Distributed AI system
- **Macalu Lite** - Lightweight component

## Getting Started

### VantaCore Backend

```bash
cd ai_ecosystem/vantacore/vantacore_backend
pip install -r requirements.txt
python src/main.py
```

### AI Dev Suite

```bash
cd ai_ecosystem/ai_dev_suite/ai_dev_suite_app
npm install
npm run dev
```

## Structure

- `ai_ecosystem/` - Main ecosystem directory containing all components
- `.github/workflows/` - GitHub Actions workflows
